# 🎬 AniVerse AI Video Studio • Universal Text-to-Video Engine

> **AniVerse Studio** is a generative video engine and SaaS dashboard designed for cinematic video generation, multi-scene screenplay breakdown, character face persistence, and instant `.webm` / `.mp4` export.

## 🌟 Key Features
* **Open Universal Story Engine:** Accepts any narrative with automated semantic environment parsing.
* **5-Step Production Pipeline:** Story Prompt, Character Casting, Style & Duration, Screenplay Shots, and 60FPS Video Render.
* **AI Director Copilot:** Real-time assistant that polishes and injects scene prompts.
* **Privacy & Merchant Security:** Built-in masked merchant checkout (`aniverse.pay@icici`). Zero personal contact exposure.
* **In-App Feedback Desk:** User tickets stream directly into the SuperAdmin Console.
